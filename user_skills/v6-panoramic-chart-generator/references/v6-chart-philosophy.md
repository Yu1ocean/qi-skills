# 三维断轴显微镜（v6）——长尾放大看数规则与制图理念

> 目标：同一张图里同时“看得见头部冲顶，也看得清尾部纹理”。

## 一、核心设计矛盾

长尾业务的数据分布通常呈现：
- 头部（少量实体/层级）占据绝大多数 GMV，数值极大；
- 尾部（大量实体/层级）数值很小但波动频繁且对策略敏感。

**线性坐标轴**会把尾部压扁到“贴地”，导致：
- 尾部波动不可读；
- 占比结构在低位被压缩；
- 汇报只能二选一：要么展示头部，要么放大尾部（失去全局）。

v6 的回答：把“坐标轴”从线性改造成**分段映射**（断轴/非线性），并让读数仍然指向真实值（反映射标签）。

---

## 二、v6 的四个关键组件

### 1) 基于日均 GMV 自动打标 T0-T6（分层是“第三维”）

**理念**：用“日均 GMV”而不是“总 GMV”做分层，避免窗口长度差异造成层级漂移；用分位点而不是固定阈值，保证跨类目/跨周期的稳定适配。

- daily_avg_gmv = ΣGMV / active_days
- 默认 7 档（越小越尾）：T6、T5、T4、T3、T2、T1、T0
- 默认切分分位点：P50 / P80 / P90 / P95 / P98 / P99.5

> T0 用于“超级头部”，T6 用于“深尾部”，中间层（T1-T5）用于观察结构迁移。

### 2) 长尾断轴（GMV 量级断轴）

**理念**：断轴不是“隐藏真实大小”，而是“重分配屏幕空间”。

- 选择 2 个断点（推荐 P90、P99）
- 三段映射：
  - 尾段（≤b1）保持近似线性，确保尾部纹理可读
  - 中段（b1~b2）适度压缩
  - 顶段（>b2）强压缩，但仍保留趋势形状

配套规则：
- 图内绘制使用映射值 f(y)
- 坐标轴标签、tooltip 展示反映射 inv(f(y))（真实值）

### 3) T1-T5 占比非线性分割防压缩

**理念**：占比图的“信息密度”集中在 0%~20% 的区间；如果用线性 0~100%，低占比层级会全部挤在底部，结构变化不可见。

做法：
- 对 share（0~1）做分段映射 g(p)
- 在 0%~若干阈值内分配更高的屏幕高度
- 同样使用反映射做读数

> v6 强调 T1-T5：因为它们通常既有规模、又足够敏感，是“结构变化”的主要承载层。

### 4) 内联图例拼接（Inline Legend Splicing）

**理念**：图例不应该抢夺绘图区。尤其是层级多（T0-T6）时，默认 legend 会显著挤压有效面积。

做法：
- 关闭默认 legend（或放图外）
- 在图内用 `graphic` 拼接色块 + 文案
- 让图例成为“标题行的一部分”，强化读图路径：标题 → 图例 → 数据。

---

## 三、落地建议（v6 默认输出）

- **断轴 GMV 趋势图**：多折线（T0~T6），y 为断轴映射值，轴标签为真实 GMV。
- **非线性占比趋势图**：多折线（重点看 T1~T5），y 为非线性映射值，轴标签为真实占比。

以上两张图组合，形成 v6 的“全景 + 显微”双视角。
