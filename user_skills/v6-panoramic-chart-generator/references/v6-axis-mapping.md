# v6 断轴与非线性映射实现约定

本文件定义 v6 出图时对“断轴 / 非线性轴”的统一实现方式，便于在不同图表（ECharts/Excel/BI）中复用同一口径。

## 1. 分段线性映射（通用模板）

给定严格递增断点：
- 原始空间断点：0 < b1 < b2 < ... < bk
- 每段压缩系数：s0, s1, ..., sk（0 < si ≤ 1）

定义分段线性映射 f(x)：
- 第 0 段：x ∈ [0, b1]
  - f(x) = x * s0
- 第 i 段：x ∈ (bi, b{i+1}]
  - f(x) = f(bi) + (x - bi) * si
- 第 k 段：x > bk
  - f(x) = f(bk) + (x - bk) * sk

其反函数 inv(y) 通过定位 y 落在哪个段的映射区间，做相同的线性反推得到。

> v6 的关键点：**只映射绘图空间，不改变读数口径**。所有对外展示（轴标签、tooltip、标注）必须是 inv 之后的真实值。

---

## 2. GMV 长尾断轴（默认参数）

### 2.1 断点选择

默认从所有绘图点（例如：按 date×T 聚合后的 GMV）上取分位点：
- b1 = P90
- b2 = P99

### 2.2 压缩系数

默认三段：
- s0 = 1.00（尾部保持线性）
- s1 = 0.20（中段轻压缩）
- s2 = 0.05（顶段强压缩）

> 若头部极端值更强，可把 s2 调到 0.02；若尾部仍被压扁，可把 b1 降到 P80。

---

## 3. T1-T5 占比非线性分割（默认参数）

占比 p ∈ [0, 1]，v6 默认使用“多段放大低占比”的映射：

原始断点（p）：
- 0
- 0.5%
- 2%
- 8%
- 20%
- 40%
- 100%

对应显示区间（u）：
- 0
- 25%
- 45%
- 60%
- 75%
- 88%
- 100%

解释：
- 0~0.5% 给到 25% 的高度，确保极小层级仍可读
- 0.5%~2% 再给 20% 高度
- 2%~8% 给 15% 高度
- 8%~20% 给 15% 高度
- 20%~40% 给 13% 高度
- 40%~100% 给 12% 高度

实现方式：把上述“原始断点 p”与“显示断点 u”当作分段线性映射的断点对，得到 g(p) 与 g^{-1}(u)。

---

## 4. ECharts 落地注意事项

- 断轴/非线性轴的“视觉效果”来源于 **对数据做映射**，并在轴标签处做反映射。
- option 输出建议使用 JS（而不是纯 JSON），以便在 formatter 中写 inv()。
- inline legend 推荐用 `graphic` 组件拼接：rect（色块）+ text（层级名）。
