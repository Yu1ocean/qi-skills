# 零信任数据分析与制图师

本技能严格遵循零信任原则，用于处理、分析数据并生成高质量图表。

## 核心原则
- **绝不盲猜数据**
- **绝不用 Mock 数据**
- **绝不说互联网黑话**（禁用“赋能”、“全链路”、“护城河”等词汇）

## 步骤一：数据源提取（风神平台取数规矩）
1.  **防风控与轮询机制**：提取风神（Aeolus）全量数据时，如遇风控拦截或熔断，严禁直接宣告失败，必须自动转入“定时轮询（如30分钟重试）”策略，直到凑齐。
2.  **资产留痕**：成功拿到风神数据后，必须提取风神看板真实名称与链接，以单行插入模式同步归档到主台账的【常用风神链接】Sheet 中。

## 步骤二：数据清洗（零信任洗表与防雷规矩）
1.  **剿灭“空格刺客”**：对任何维度字段（如 Country、Tier）聚合前，强制执行 `.str.strip()` 剔除首尾空格。
2.  **拒绝“外星标签”与强制重塑**：拿到表后必须先跑唯一值枚举探针，绝不盲信原始标签。必须严格按业务共识硬编码分箱：
    *   **达人（Creator）**：依据日均 GMV 绝对值阈值（T6>=3.3k, T5>=1k, T4>=0.33k, T3>=0.11k, T2>=0.008k）重新聚合为 T1-T6。
    *   **商家（Seller）**：提取底层原生字段 `gmv_tier_1d`，商家自带 T1-T5，无需强行按 GMV 切分。
    *   ⚠️**核心兜底**：如果没有标准，向用户询问。
3.  **飞书写入“防幽灵”机制**：将透视数据落盘到飞书电子表格前，必须先物理清空旧数据所在的数据范围，再写入新数据，绝对禁止局部覆盖写入。
4.  **触发异构双引擎质检**：核心产出必须经过“Pandas内存聚合”与“纯SQL”两套异构逻辑背靠背重算，北极星指标对齐后才可进入下一步。

## 步骤三：绘制图表（防重叠与排版规矩）
1.  **数据纯度红线**：严禁使用随机数或 Mock 数据，100% 读取清洗落盘的CSV或透视表。
2.  **标签防重叠机制**：柱状图绝对值标签极差大时强制旋转90度垂直显示；堆叠图占比 <5% 的切片区块强制隐藏标签。
3.  **复合视图规范**：左侧绝对值对比支持对数坐标及ARPU倍数Badge（US为1.0x基准）；中右侧为 100% 结构堆叠图。
