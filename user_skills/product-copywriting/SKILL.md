# 产品文案（product-copywriting）

> 包目录保持为 `user_skills/product-copywriting/`，技能编号继承为 `SKL-2605-001`，对用户的自然触发口径统一为「产品文案」。

## Common Rationalizations（常见借口库）

- “用户只给了几个卖点，我先写一版试试，缺什么以后再补。”
- “Benefit 大概就是更方便、更高级，先不追问具体结果也行。”
- “Evidence 没给也没关系，先写得像真的。”
- “这次先给 1 个版本，另外 2 个方向以后再展开。”
- “3 个方向换几个形容词就够了，不必真做策略差异。”
- “Slogan 和视觉符号只是包装层，可有可无，先把正文写完再说。”

## Red Flags（危险信号）

- FABE 任一项缺失，却直接开始写成稿。
- Benefit 只有“更好 / 更方便 / 更高级 / 更舒适”之类空泛表述，却未继续追问。
- Evidence 缺失、模糊或不可验证，却继续使用绝对化承诺。
- 只输出 1 个版本，或 3 个版本只是词语改写，没有明显策略分化。
- 五步法顺序被打乱，没有先回答“顾客要完成什么任务”。
- 文案仍然是品牌腔、说明书腔、客服腔，不像活人会说的话。
- 任一方向缺少 `Slogan 短句` 或 `视觉锤符号`，却宣称输出完整。

## Verification（强制验收清单）

- `scripts/fabe_validator.py` 可接收 JSON 字符串或 JSON 文件，能识别 FABE 缺项、空泛 Benefit、缺失 Evidence，并在 `--strict` 模式下执行运行时熔断。
- `SKILL.md` 明确要求：FABE 未补齐时，唯一允许的输出是结构化追问，不得抢跑生成文案。
- 正式生成阶段必须输出 **3 个创意方向**；每个方向都要包含：方向名、主轴 / 策略差异、文案气质、一句话预览、`Slogan 短句`、`视觉锤符号`、完整成稿、五法拆解、3 条备选短句。
- 三个方向必须彼此存在策略差异，允许根据产品动态命名，不得写死为唯一模板。
- `output/product-copywriting_skill_doc.lark.md` 包含一套完整模拟案例，展示“FABE 完整 → 无需追问 → 三方向生成”的闭环，且案例中完整展示新增字段。

## 📌 技能简介

这个技能用于把产品信息升级成真正可投放、可挂车、可做详情页卖点位的产品文案。

它不是直接“把卖点润色一下”，而是先把用户输入过一遍 **FABE 校验**，确认 Feature / Advantage / Benefit / Evidence 四项是否完整；只有信息齐全后，才按 **顾客任务思维 → 场景思维 → 情绪思维 → 活人思维 → 身份证思维** 五步法生成文案。

相较上一版，这次迭代新增了两个稳定的品牌记忆锚点：**`Slogan 短句`** 与 **`视觉锤符号`**。也就是说，每次不只要产出 3 个彼此有明显策略差异的方向，还要为每个方向补齐“短句记忆点 + 具象视觉锚点”，方便直接用于包装、主图、KV 或短视频封面。

## ⚙️ 核心架构 / SOP / 约束条件

### 输入格式

推荐用户尽量按下面字段提供信息；其中 FABE 为硬门槛，后面的目标人群 / 场景 / 风格偏好会增强输出质量：

- 产品名称
- 产品类别
- Feature（特征）
- Advantage（优势）
- Benefit（利益）
- Evidence（证据）
- 目标人群（可选）
- 使用场景（可选）
- 希望传达的情绪 / 气质（可选）
- 参考文风（可选）
- 禁用词 / 禁区（可选）

### 合规默认值（Defaults / L2）

- 默认输出语言：中文简体
- 默认创意方向数：`3`
- 默认方向策略：优先选择差异最大的 3 个切入面，而不是 3 个近似版本
- 默认追问策略：当 FABE 不完整时，先输出结构化追问，不生成正文
- 默认 Benefit 判定：若只出现“更好 / 更方便 / 更高级 / 更舒适 / 体验更好”等空泛收益，视为未补齐
- 默认 Evidence 判定：若无测试、数据、认证、案例、用户反馈或可验证事实支撑，视为需追问
- 默认成稿长度：每个方向 80-150 字，可按平台字数约束微调
- 默认文案气质：每个方向用一句短语明确语言风格与情绪基调
- 默认一句话预览：每个方向先给 1 句 20-40 字的预览，帮助快速比较方向差异
- 默认 `Slogan 短句`：每个方向输出 1 句 8-16 字的高浓度记忆点短句，可直接用于包装 / 主图 / 短视频封面
- 默认 `视觉锤符号`：每个方向输出 1 个具象意象，可用 emoji + 物件描述，也可直接给出具体视觉元素，要求能被设计或视频画面承接
- 默认短句数量：每个方向额外输出 3 条可独立使用的备选短句

### 运行流程（SOP）

#### 第 1 步：接收并整理产品信息

先把用户输入结构化，至少抽取出 FABE 四项；不要一上来直接润色 Feature。

#### 第 2 步：执行 FABE 校验

优先判断：

1. **Feature** 是否是客观事实，而非情绪形容词。
2. **Advantage** 是否回答了“相比普通方案 / 旧方案 / 竞品，好在哪里”。
3. **Benefit** 是否回答了“用户最终多得到什么结果、少承受什么麻烦、获得什么感受”。
4. **Evidence** 是否提供了可验证支撑，如数据、测试、认证、用户反馈、案例、真实表现。

若 FABE 不完整，必须停止生成，按下面格式追问：

```text
【FABE 信息待补全】
- 已有信息：
- 缺失信息：
- 需继续具体化：
- 请补充回答：
  1. 
  2. 
  3. 
```

#### 第 3 步：FABE 齐全后，按五步法生成

生成时必须按以下顺序思考，不允许跳步：

1. **顾客任务思维**：用户真正想完成什么任务，不只是想买什么产品。
2. **场景思维**：补出一个具体时刻，让用户脑中出现真实画面。
3. **情绪思维**：把“解决问题”升级成“情绪被照顾、状态被改变”。
4. **活人思维**：删掉说明书腔、汇报腔，用自然的人话表达。
5. **身份证思维**：把产品写成某种审美、态度或生活方式的表达。

#### 第 4 步：发散出 3 个创意方向

这一步是本技能相对原 Prompt 的升级重点。

要求如下：

- **必须输出 3 个方向**，不能少于 3 个。
- 3 个方向要有**明显策略差异**，而不是只换同义词。
- 方向名称允许动态生成，优先根据产品和用户心智命名。
- 方向差异可以体现在：
  - 主诉求不同（例如效率、安心、体面、愉悦、表达自我）
  - 主场景不同（例如通勤、夜归、露营、会议、送礼）
  - 主情绪不同（例如松弛、掌控、被照顾、轻盈、体面）
  - 主身份不同（例如务实派、精致派、审美派、专业派、极简派）
- 若用户指定平台或场景（抖音、小红书、详情页、海报、直播口播），则 3 个方向都要适配该语境，但仍要保留差异。

#### 第 5 步：为每个方向补齐记忆锚点

在完成方向策略后，每个方向必须继续补齐以下 4 个字段，不能只写正文：

- **文案气质**：说明这个方向整体的语言气场，例如“利落清醒”“松弛克制”“体面而有分寸”。
- **一句话预览**：用 1 句话概括这个方向最打动人的切口，让用户在阅读全文前先完成筛选。
- **Slogan 短句**：给出 1 句高浓度记忆点短句，适合包装、主图或短视频封面。
- **视觉锤符号**：给出 1 个可被视觉化承接的意象或符号，例如“☕ 通勤包侧袋里冒热气的咖啡杯”“车载杯架中的小钢炮”。

#### 第 6 步：按固定格式输出

FABE 完整后，正式输出必须使用以下结构：

```text
【FABE 校验结果】
- 状态：完整，可进入文案生成
- Feature：...
- Advantage：...
- Benefit：...
- Evidence：...

【创意方向 1｜<动态方向名>】
- 主轴 / 策略差异：...
- 文案气质：...
- 一句话预览：...
- Slogan 短句：...
- 视觉锤符号：...
- 完整成稿：...
- 五法拆解：
  1. 顾客任务：...
  2. 使用场景：...
  3. 情绪价值：...
  4. 活人表达策略：...
  5. 身份表达：...
- 备选短句：
  1. ...
  2. ...
  3. ...

【创意方向 2｜<动态方向名>】
...

【创意方向 3｜<动态方向名>】
...
```

> `Slogan 短句` 与 `视觉锤符号` 属于固定输出字段，不允许省略，也不能混写进完整成稿里代替。

#### 第 7 步：生成前后自检

在提交结果前，至少逐条自检：

- 我写的是用户任务，而不只是产品卖点吗？
- 我写出了一个具体场景，而不只是抽象形容词吗？
- 文案里有情绪价值，而不只有功能价值吗？
- 句子像活人会说的话吗？
- 文案是否暗示了某种身份、审美或态度？
- 三个方向之间是否真的有策略差异？
- 每个方向的 `Slogan 短句` 是否能独立成立，并具备记忆点？
- 每个方向的 `视觉锤符号` 是否足够具象，能被设计或画面承接？
- 删掉品牌名后，文案本身还有吸引力吗？

### 本地脚本与验证（L3 运行时护栏）

本技能提供 `scripts/fabe_validator.py` 作为可执行的本地校验脚本：

```bash
python3 user_skills/product-copywriting/scripts/fabe_validator.py \
  --json '{"产品名称":"便携咖啡机","Feature":["680g 机身"],"Advantage":["比手冲更省事"],"Benefit":["早八前 3 分钟喝到热咖啡"],"Evidence":["实测 180 秒完成加热萃取"]}'
```

如果希望在自动化流程里把“不完整 FABE”直接熔断，可加 `--strict`：

```bash
python3 user_skills/product-copywriting/scripts/fabe_validator.py \
  --file user_skills/product-copywriting/references/demo_incomplete.json \
  --strict
```

### 约束条件

- FABE 未补齐时，**禁止**直接写正文。
- 不得把空泛 Benefit 视作“已提供”。
- 不得自动脑补 Evidence。
- 不得出现无法验证的绝对化承诺，如“100%”“永久”“全网第一”。
- 不得写成品牌自嗨或客服话术，重点始终是用户任务与用户感受。
- 不得输出 3 个高度同质的版本；必要时要先重新定义方向，再开始成稿。
- 不得省略 `文案气质`、`一句话预览`、`Slogan 短句`、`视觉锤符号` 这 4 个固定字段。
- `视觉锤符号` 必须是可具象化元素，不能写成抽象概念词，例如“高级感”“品质感”。

## 📖 案例实录 (Best Practice)

- 🧑‍💻 用户输入：
  ```text
  我有一款便携咖啡机，请先检查 FABE 信息是否完整；如果完整，再给我 3 个产品文案方向，适合电商详情页和挂车文案，并且每个方向补上 Slogan 和视觉锤。
  ```
- 🤖 标准输出：
  ```text
  【FABE 校验结果】
  - 状态：完整，可进入文案生成
  - Feature：680g 机身；常温水模式约 180 秒完成加热萃取；20bar 压力泵；Type-C 充电，满电可连续制作 5 杯。
  - Advantage：比手压式更省步骤，比路上现买更省时间，比传统家用机更轻更小。
  - Benefit：早高峰也能在 3 分钟内喝到热咖啡；移动场景中保持稳定口感与清醒状态；让喝咖啡回到自己的节奏。
  - Evidence：实测 180 秒完成加热与萃取；680g 机身；满电可制作 5 杯；20bar 参数可核验；92% 试用用户反馈减少排队买咖啡频次。

  【创意方向 1｜早八不掉线】
  - 主轴 / 策略差异：突出“通勤提效 + 先稳住状态”。
  - 文案气质：利落、清醒、带一点掌控感。
  - 一句话预览：出门前不用跟排队赌运气，3 分钟热咖啡让早八先稳住。
  - Slogan 短句：清醒，不等排队。
  - 视觉锤符号：☕ 通勤包侧袋里冒热气的迷你咖啡杯。
  - 完整成稿：你不是想多背一台机器出门，只是不想把早上的状态交给排队和将就。680g 的机身塞进通勤包里，常温水约 3 分钟就能做出一杯热咖啡；到公司前、开会前、上车后，你拧开它的时候，第一口就已经把人从慌乱里拉回正轨。
  - 五法拆解：
    1. 顾客任务：快速拿回清醒状态。
    2. 使用场景：早高峰出门后、到公司前 10 分钟、会议开始前。
    3. 情绪价值：从慌乱切换到稳定与可掌控。
    4. 活人表达策略：用“别把状态交给排队和将就”代替说明书话术。
    5. 身份表达：重视效率，也重视自己状态管理的人。
  - 备选短句：
    1. 早八之前，先把热咖啡握在自己手里。
    2. 不用绕路排队，也能喝到像样的一杯。
    3. 把清醒装进包里，不装进运气里。

  【创意方向 2｜把仪式感带上路】
  - 主轴 / 策略差异：突出“路上也能保留自己的节奏与松弛感”。
  - 文案气质：有画面、松弛、克制，不硬推销。
  - 一句话预览：赶时间，不代表要把每天第一口热咖啡也一起将就。
  - Slogan 短句：路上，也有热咖啡。
  - 视觉锤符号：🚗 车载杯架里稳稳立着的一杯热咖啡。
  - 完整成稿：出门可以很赶，但喝咖啡这件事，不必永远交给便利店和排队。车里等红灯的时候、到公司楼下的那几分钟、周末短途出发前，这台便携咖啡机会把你熟悉的那一口热咖啡带到身边。不是为了多高级，而是让一天开始的时候，哪怕在路上，也还有一点属于你自己的节奏和松弛感。
  - 五法拆解：
    1. 顾客任务：在移动途中保住熟悉的日常感。
    2. 使用场景：车里等人、公司楼下、短途出发前、会议前空档。
    3. 情绪价值：熟悉、安稳、被照顾。
    4. 活人表达策略：用“车里等红灯的时候”这种具体画面拉近感受。
    5. 身份表达：就算在赶路，也愿意给自己留一点体面和仪式感的人。
  - 备选短句：
    1. 在路上，也能有一杯按自己节奏来的热咖啡。
    2. 赶时间，不代表要一直将就。
    3. 把熟悉的那一口，带到每一次出门里。

  【创意方向 3｜会自己照顾自己的那种人】
  - 主轴 / 策略差异：突出“自我照顾 + 身份审美表达”。
  - 文案气质：克制、有分寸、带轻微审美感。
  - 一句话预览：它不只是提神工具，更像一种把自己照顾好的日常表达。
  - Slogan 短句：把状态，照顾得体面。
  - 视觉锤符号：👜 通勤包里露出半截银色咖啡机机身。
  - 完整成稿：有些人选咖啡，不只是为了提神，也是为了让自己在再忙的日子里，依然保留一点讲究。它很轻，能装进包里；也很快，常温水约 3 分钟就能给你一杯热咖啡。真正打动人的，不是参数写得多漂亮，而是它让“我会照顾自己的状态”这件事，变得具体又日常。
  - 五法拆解：
    1. 顾客任务：在高密度工作和移动生活里维持自己的状态和标准。
    2. 使用场景：通勤包、办公桌、车里、短途出行等“轻便但不将就”的场景。
    3. 情绪价值：体面、自我照顾、从容。
    4. 活人表达策略：用“再忙也保留一点讲究”代替冷参数堆砌。
    5. 身份表达：重视自我节奏、审美与生活质感的人。
  - 备选短句：
    1. 会选它的人，通常都很会照顾自己。
    2. 再忙，也不想把每天第一口热咖啡过得太随便。
    3. 它不是为了抢戏，而是让你的状态始终在线。
  ```
