## 从原始 Prompt 提炼出的基础规则

### 1. 先 FABE，后生成

原文明确要求：进入文案生成之前，必须先补齐 FABE 四要素：

- Feature（特征）
- Advantage（优势）
- Benefit（利益）
- Evidence（证据）

如果缺任一项，尤其是 Benefit 过于空泛或 Evidence 缺失，不能直接开始写文案，必须先追问。

### 2. 五步法生成主线

原文的文案生成流程是：

1. 顾客任务思维
2. 场景思维
3. 情绪思维
4. 活人思维
5. 身份证思维

这五步共同作用，目标不是把卖点说清楚，而是让用户：

- 在脑中先出现使用画面
- 在情绪上先喜欢它
- 在身份上觉得它适合自己

### 3. 写作改写规则

原文给出的核心改写原则包括：

- 少讲配置，多讲结果
- 少讲概念，多给画面
- 少讲正确，多讲情绪
- 少讲品牌，多讲人
- 少做硬推销，多做身份暗示

### 4. 基础输出结构

原始 Prompt 的基础输出结构是：

- 1 条完整产品文案
- 1 份五法拆解
- 3 条备选短句

## 本技能的升级点

### 升级 1：从“1 条文案”升级为“3 个创意方向”

这是本技能相对原 Prompt 的最大升级。

- 不再只输出 1 个版本。
- 每次必须输出 3 个彼此有明显策略差异的方向。
- 方向名称允许根据产品和场景动态命名，不写死为唯一模板。
- 允许的差异维度包括：任务、场景、情绪、身份、平台语境、表达节奏。

### 升级 2：加入本地可执行校验脚本

新增 `scripts/fabe_validator.py`：

- 支持 JSON 字符串 / JSON 文件输入
- 输出 FABE 缺项、空泛 Benefit、Evidence 问题和追问建议
- 在 `--strict` 模式下可直接熔断，满足 CDA 的 L3 运行时断言要求

### 升级 3：补齐技能级规范文档

围绕当前 skill 规范补齐了：

- Frontmatter（`name` / `id` / `version` / `description`）
- `Common Rationalizations` / `Red Flags` / `Verification`
- `📌 技能简介` / `🔑 触发词` / `⚙️ 核心架构 / SOP / 约束条件` / `📖 案例实录 (Best Practice)`
- `CHANGELOG.md`
- 本地飞书文档草稿 `output/product-copywriting_skill_doc.lark.md`

### 升级 4：为每个方向补齐品牌记忆锚点

本轮 `1.1.0` 迭代新增了 4 个固定输出字段，用于把“能读”的文案升级成“能被记住、能被设计承接”的文案方案：

- `文案气质`：明确方向的语言风格与情绪基调
- `一句话预览`：先给使用者一个可快速筛选方向的摘要句
- `Slogan 短句`：提供可直接落到包装 / 主图 / 短视频封面的高浓度记忆点
- `视觉锤符号`：提供可被 KV、主图、包装或视频镜头承接的具象视觉意象

这 4 个字段不来自原始 Prompt，而是本技能在用户级落地时补上的结构化升级，用于缩短从“文案方向”到“视觉执行”的距离。

## 建议用途

- 商品详情页文案
- 短视频挂车文案
- 海报卖点位
- 直播口播底稿
- 新品卖点包装

## 不建议跳过的环节

- 不要跳过 FABE 校验
- 不要把空泛 Benefit 当成已补齐
- 不要在没有 Evidence 的情况下直接写绝对化结论
- 不要把 3 个方向写成同一套句子换词
- 不要遗漏 `Slogan 短句` 与 `视觉锤符号`，否则无法形成完整方向方案
