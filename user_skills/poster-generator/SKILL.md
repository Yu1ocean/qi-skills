# Poster Generator Skill

## Background

poster-generator v1.4 面向 TikTok Shop 商家传播物料生成场景，核心任务不是“做一张好看的图”，而是把品牌规范、业务场景、受众优先级和可用事实压缩成可直接执行的海报方案。

本版本吸收了 2026-07-21 完成的 Q1-Q6 需求采集结果，新增了以下知识锚点：

- **品牌规范来源**：TikTok Shop 品牌视觉规范摘要、TikTok Shop 官方物料规范文档。
- **参考样例来源**：AI 模拟机场广告 demo、竞品调研 Wiki。
- **业务优先级**：P0 招商类 / 权益政策类，P1 战报奖项类 / 线下物料类，P2 活动大促类。
- **主要受众**：商家为主，服务商为辅；战报类可外溢到媒体，但不能把媒体作为核心第一受众。
- **搭建授权**：Jason 已明确回复“开始搭建吧！”，说明需求采集结束，可进入正式执行阶段。

## Common Rationalizations

- “用户只给了活动名，先随便补一堆卖点。”
- “海报文字越多越完整。”
- “先生成图，后面再考虑尺寸和文案层级。”
- “数据没有来源也可以写成战报数字。”
- “图片里有二维码/Logo/奖项名称，模型会自然处理好。”

这些做法会让海报变成信息噪音或事实幻觉。海报生成必须先锁定用途、尺寸、主信息、主体视觉和可用事实，再进入视觉生成。

## Red Flags

出现以下任一情况必须先收敛或标记缺口：

- 缺少活动名称、主题或主标题，且上下文无法合理推断。
- 用户要求展示具体 GMV、排名、增长率、奖项，但没有提供数值或来源。
- 用户要求生成真实二维码、真实未提供 Logo、可识别真实人物肖像。
- 海报文案超过 1 个主标题、2 个副信息层、3 组关键数据。
- 未确认画幅却默认生成不适配投放渠道的尺寸。
- 画面中出现未授权品牌标识、错误品牌 Logo、错误品牌色或与 TikTok Shop 规范冲突的品牌资产。
- 文案中出现“话术”、将 TikTok 描述为媒体、或主动点名竞对品牌。

## Constraints

### 禁用项（5 条硬约束）

1. 禁止使用“话术”一词描述商家沟通、招商动作或营销表达。
2. 禁止把 TikTok 描述为“媒体”；如需露出平台，仅使用 TikTok Shop 品牌表达。
3. 禁止在正式物料中点名竞对品牌，例如亚马逊。
4. 禁止错误使用 TikTok Shop 品牌标识、品牌色、Logo 安全边距或非官方视觉资产。
5. 禁止混入未授权品牌元素、未确认来源的口号、二维码、奖项、排名或人物肖像。

### 事实与素材约束

- 可用素材默认来自品牌规范文档、竞品调研 Wiki、AI 模拟机场广告 demo，以及用户后续补充的官方图片或数据。
- demo 只作为方向参考，不视为质量上限，不直接复刻版式。
- 没有官方素材时，可以生成风格接近的抽象主视觉或 mockup，但必须避免伪造真实合作方资产。

## Tone

- **招商类**：强调机会、资源、平台价值，但语言要像商业海报，不写成销售沟通稿。
- **权益 / 政策类**：利益点、门槛、截止时间优先，信息顺序必须比装饰优先级更高。
- **战报 / 奖项类**：突出结果、数据、方法论干货，避免只剩“庆祝感”没有业务信息。
- **线下物料类**：气势感和信任背书优先，保证远距离可读性。
- **活动大促类**：允许更年轻、更轻快，但不能牺牲品牌感和规则边界。

## Verification

交付前逐项检查：

1. **输入完整性**：活动名称、主题、主标题齐备；缺口已显式标记为 `[待补充]`。
2. **场景优先级**：先判断是否属于 P0 / P1 / P2，再决定信息密度、语气和视觉资源投入。
3. **受众匹配**：明确主受众是商家还是服务商，主画面和 CTA 不能同时服务过多对象。
4. **尺寸匹配**：移动端传播默认 `9:16`；横版汇报默认 `16:9`；社媒方图默认 `1:1`。
5. **文案层级**：主标题 1 条，副标题 0-1 条，数据 0-3 组，底部 CTA 0-1 条。
6. **禁用项合规**：逐条检查 5 条禁用项，尤其是品牌标识、竞对、媒体表述和未授权素材。
7. **事实安全**：所有数字、奖项、排名、日期来自用户输入或材料；无法确认的不编造。
8. **视觉一致性**：风格与用途匹配，主体视觉没有遮挡标题，中文文字清晰。
9. **运行时断言**：使用 `scripts/build_poster_prompt.py` 生成提示词时必须通过必填字段、尺寸、场景与禁用词校验。

## Defaults

- 默认场景优先按 `P0 > P1 > P2` 执行；当用户一次给出多个任务时，先产出 P0 物料。
- 默认主受众：商家；如任务明显为服务商组织招商会，可切换为“商家 + 服务商”双主受众。
- 默认画幅：`9:16`，适合移动端传播与长图海报。
- 默认视觉调性：招商 / 奖项 / 线下高规格场景优先 `高级感`；社媒传播优先 `年轻化`；机场广告 / 全球榜单优先 `国际范`。
- 默认风格：`award_premium`，适合奖项、案例、战报类商业海报。
- 默认数据上限：最多 3 组关键数据，超过时只保留最能支撑主标题的 3 组。
- 默认事实策略：未提供的数据、排名、奖项、日期不自动编造，统一标记为 `[待补充]` 或不入画。
- 默认二维码策略：不生成真实二维码，只保留“扫码了解/扫码报名”占位区，除非用户提供可用二维码图片。
- 默认肖像策略：人物仅使用模糊或非真实人物，不生成可识别真实人脸。

## 设计规律

从用户提供的商家 showcase 海报与新增 Q1-Q6 背景中提炼以下稳定模式：

1. **竖版优先**：多数海报为移动端竖版，信息从上到下阅读；常见比例接近 `9:16`、`3:4` 或长图。
2. **三段式结构**：顶部品牌 / 平台背书，中部主标题 + 主视觉，底部数据、权益、CTA 或二维码区。
3. **高端色彩**：黑金、深蓝金、紫蓝霓虹、米金浅色是主流；金色用于奖项、荣誉、关键数字，白色用于正文高对比。
4. **主视觉中心化**：产品图、奖杯、舞台、案例截图通常占画面中部 35%-55%；用光环、边框、玻璃卡片或舞台光突出。
5. **大字压场**：主标题最大，常配月桂、奖杯、金属立体字、发光描边；副标题和解释严格降级。
6. **数据模块化**：战报类海报常用 2-3 个大数字；每个数字下方有一句解释，避免超过三组。
7. **平台可信背书**：顶部常出现 TikTok Shop Logo、活动 IP、品牌 Logo 或 Slogan；底部可放来源、日期、CTA。
8. **装饰不抢信息**：粒子、金线、弧形门、星空、赛博渐变、购物袋、扩音器等只做氛围，不遮挡文字。
9. **场景先于美术**：P0 场景优先保证信息清楚和可信感，P1 场景强调结果与荣誉，P2 场景才允许更强的社媒包装。
10. **机场 / 国际传播参考**：mockup 场景可借鉴机场大屏、城市户外屏、国际品牌广告位，但版面语言要更克制、减少本地化喊话。

## 风格预设

### award_premium

适合奖项、年度榜单、品牌荣誉、闭门会、线下高规格活动。使用黑金或深棕金背景、金属立体字、月桂、奖杯、聚光灯、环形光效。默认归属 `高级感` 调性，主标题应短而硬，例如“年度最佳合作伙伴”。

### case_tech

适合 TikTok Shop 案例集、商家增长案例、IP 活动复盘。使用紫蓝渐变、玻璃拟态信息卡、霓虹边框、局部 3D 小图标。适合呈现品牌图 + 2 组关键数据，兼容 `年轻化` 或偏理性的 `国际范`。

### brand_product

适合新品、旗舰商品、招商商品展示。产品大图居中，卖点参数一行或两行展示，CTA 放底部。背景可以是星空、舞台、科技场景或浅色高级质感，适合招商类和活动大促类。

### clean_light

适合证书、轻奢、家居、美妆等更柔和的品牌调性。使用米金、香槟金、浅灰背景；减少强烈霓虹，突出奖杯、证书或产品质感，适合需要更克制的 `高级感` 或 `国际范`。

## SOP

1. **提取输入**：从用户消息、文档或表格中抽取输入字段。若缺少必填字段且无法推断，向用户做选择题式补齐；不要开放式追问。
2. **判断场景分级**：先归类到 `P0`、`P1` 或 `P2`，再确认对应 `scene_type`、主受众和传播目标。
3. **锁定调性**：在 `高级感`、`年轻化`、`国际范` 三类中选择一档；如果用户给了明确场景，以场景优先，不以个人审美优先。
4. **判定用途与尺寸**：移动端传播默认 `9:16`；汇报页默认 `16:9`；社媒方图默认 `1:1`。用户指定尺寸时优先用户指定。
5. **压缩文案**：将文案压成“1 个主标题 + 1 个副标题 + 0-3 组数据 + 0-1 条 CTA”。多余信息进入备注，不进入画面。
6. **执行禁用项过滤**：检查 5 条硬约束，移除竞对点名、媒体表述、错误品牌资产和未授权素材。
7. **选择风格预设**：按业务场景与调性选择 `award_premium`、`case_tech`、`brand_product` 或 `clean_light`。
8. **生成提示词**：将字段写入 JSON，运行 `scripts/build_poster_prompt.py` 生成标准提示词。
9. **调用图片生成**：使用 `image-generate` Skill 生成海报。执行时通过 bash 直接运行 `python script/image_generator.py`，设置 `include_secrets=true`。
10. **自检交付**：检查标题层级、关键事实、尺寸、受众、品牌合规和输出路径。若文字或事实不稳，收敛文案后重新生成。

## 脚本用法

将输入写成 JSON：

```json
{
  "scene_priority": "P0",
  "scene_type": "招商类",
  "primary_audience": "商家",
  "tone_category": "premium",
  "activity_name": "TikTok Shop 金营奖",
  "theme": "年度服饰营销大奖获奖海报",
  "primary_message": "2023 年度服饰营销大奖",
  "subtitle": "借助品类 IP 实现从工厂到品牌升级",
  "metrics": [
    {"label": "年度 GMV", "value": "7亿"},
    {"label": "粉丝增长", "value": "142%"},
    {"label": "会员增长", "value": "40万"}
  ],
  "hero_visual": "品牌白色运动鞋产品图 + 金色奖杯",
  "logos": ["TikTok Shop", "品牌名"],
  "aspect_ratio": "9:16",
  "style": "award_premium"
}
```

运行：

```bash
python3 scripts/build_poster_prompt.py --input poster_input.json --output poster_prompt.txt
```

随后把 `poster_prompt.txt` 的内容交给 `image-generate`，并按 `aspect_ratio` 传入同样比例。

## 输出格式

默认输出一张图片文件，并在回复中给出：

- 海报文件路径或云端直达链接。
- 使用的画幅与风格预设。
- 入画主文案清单。
- 被压缩到备注区、未入画的信息。

如用户要求飞书文档归档，则另行使用飞书文档写入能力创建说明文档，避免把长篇说明塞进聊天消息。
