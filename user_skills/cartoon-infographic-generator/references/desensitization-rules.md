# 脱敏规则（desensitization-rules）

当用户提到“脱敏”“敏感”“不要人名数字”“不要品牌”“不要暴露业务细节”时，按以下顺序处理。

## A. 人名脱敏

- 单个真实姓名 → `核心主播 / 负责人 / 核心成员`
- 多人梯队 → `头部成员 / 中坚成员 / 新人梯队`
- 禁止保留可直接识别身份的中英名组合

## B. 品牌与主体脱敏

- 品牌名 → `某品牌`
- 店铺名 → `某店铺`
- 项目名 → `某项目`
- 若品牌识别度本身就是关键结论，则先征求用户是否保留

## C. 数字脱敏

### 默认推荐
- 精确金额 → 量级表达（如“数万级”“百万级”）
- 精确单量 → 区间或趋势（如“显著提升”“接近翻倍”）
- 精确份额 → 领先表达（如“头部份额”“领先区间”）

### 宽松模式
可保留：
- 百分比变化
- 大致量级
- 非敏感效率指标

### 严格模式
统一改写为：
- `显著增长`
- `稳定提升`
- `进入头部`
- `形成规模`

## D. 排名脱敏

- 第 1 名 / Top1 → `头部领先`
- Top3 / Top5 → `第一梯队`
- 精确市占率 → `高份额 / 领先份额`

## E. 图面自检

出图前逐条确认：

- 是否仍残留真实人名？
- 是否仍出现品牌名或店铺名？
- 是否暴露精确金额、份额、单量？
- 是否可通过多个细节拼接回真实主体？

若上述任一答案为“是”，则继续收紧表达，不要带病输出。
