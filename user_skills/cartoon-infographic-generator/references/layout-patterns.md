# 布局模式（layout-patterns）

## 1. 竖版 9:16：战报型

适合复盘、业绩、增长类内容。

### 推荐结构
1. 顶部标题区：一句结果型标题 + 一句副标题
2. 第二屏区：3 张关键指标卡片
3. 中段区：能力建设 / 关键动作 / 变化原因
4. 下段区：梯队结构、方法论图示或路线图
5. 底部区：下一阶段动作 / 口号式收束

### 视觉建议
- 标题区用大字 + 小图标
- KPI 区用圆角卡片
- 中段可用箭头或流程线串联
- 梯队变化适合用金字塔或分层卡片

## 2. 竖版 9:16：方法论型

适合 SOP、培训、认知框架、策略拆解。

### 推荐结构
1. 标题：一句方法论定义
2. 核心框架：3~4 个步骤纵向排布
3. 每步配 1 个图标 + 1 句解释
4. 底部给出“如何落地”或“常见误区”

## 3. 横版 16:9：汇报型

适合电脑端展示、周会过稿。

### 推荐结构
- 左侧：标题 + 核心战绩
- 中间：3 张指标卡
- 右侧：策略与下一步

### 适用条件
- 用户明确要求横版
- 信息更偏汇报而不是传播海报

## 4. 模块裁剪规则

若原文信息太多，按以下优先级裁剪：

1. 先保留结论与核心战绩
2. 再保留 3 张最有记忆点的指标卡
3. 再保留 2~3 个最关键原因或动作
4. 最后保留下一阶段策略
5. 次级案例、长解释、过程细节优先删掉
