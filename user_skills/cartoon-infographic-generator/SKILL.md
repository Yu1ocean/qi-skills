# 中文卡通信息图生成器（cartoon-infographic-generator）

> 包目录固定为 `cartoon-infographic-generator/`，技能编号固定为 `SKL-2606-001`。

## Common Rationalizations（常见借口库）

- “先把原文大段塞进图里，后面再压缩。”
- “用户没说脱敏，那我默认保留人名、品牌名和精确数字。”
- “信息图就是把标题、数字、结论平铺一下，不用做信息分层。”
- “用户要卡通风，我只要多写几个可爱元素就行，不必考虑阅读效率。”
- “先生成一版图，核心指标不对再改。”

## Red Flags（危险信号）

- 尚未提炼 `1 个主标题 + 3~5 个核心信息块`，就直接开始出图。
- 同时出现太多数字、太多段落或太多模块，导致手机端一屏无法抓重点。
- 需要脱敏却仍保留真实人名、品牌名、绝对金额、精确份额或敏感排名。
- 画面元素很多，但没有主视觉路径，用户第一眼不知道先看哪里。
- 关键信息卡片仍然沿用原文口径，没有根据用户要求替换指标。
- 把“手绘卡通风格”理解成幼稚堆砌，反而损失专业感。

## Verification（强制验收清单）

宣称“信息图方案完成”时，至少满足以下条件：

1. 已提取并压缩出 **一个结果型标题**。
2. 已把正文蒸馏为 **3~5 个模块**，每个模块最多 1 个主句 + 2~4 个关键词。
3. 已明确 **版式比例**（默认 9:16 竖版；若用户要求汇报图，则切为 16:9 横版）。
4. 已给出 **视觉风格说明**（手绘、留白、少量图标、趣味元素但不喧宾夺主）。
5. 若用户要求脱敏，已明确执行 **人名 / 品牌 / 数字 / 排名** 的脱敏策略。
6. 若输出为图像生成提示词，提示词中已包含：内容结构、风格、版式、文字语言、脱敏要求。
7. 若进行了二次修改，已明确列出“替换了哪些指标卡片 / 删除了哪些敏感信息”。

## 📌 技能简介

这个技能用于把“长文档 / 飞书文件 / 复盘材料 / 策略总结”快速压缩成一张**可读、可传播、适配手机端**的中文信息图方案。

它不是简单摘要，而是把内容重组为“标题—关键战绩—结构分区—下阶段动作”的视觉表达。默认采用**手绘卡通风 + 运营汇报可读性**的平衡路线：有趣，但不幼稚；信息精简，但不失真。

## ⚙️ 核心架构 / SOP / 约束条件

### 1. 输入形态

优先接受以下任一输入：

- 飞书文件 / 飞书文档 / 网页链接
- 本地文档、Markdown、PDF、图片 OCR 文本
- 用户直接粘贴的报告正文
- 已有复盘摘要或 bullet points

若输入是链接，先读取内容，再进入版式抽取；不要在未读源材料的情况下直接臆造模块。

### 2. 默认目标

默认目标是输出一张：

- **中文简体**
- **竖版 9:16**
- **手机端优先**
- **手绘卡通风格**
- **少量图标/涂鸦元素**
- **留白充足、关键词突出**

若用户明确指定为横版汇报图，则改为 16:9，并保留同样的信息压缩逻辑。

### 3. 内容蒸馏流程

#### 第 1 步：先抽“主命题”

先回答这份材料真正要传达什么：

- 是“战绩型”——强调增长、领先、突破；
- 是“方法型”——强调 SOP、打法、框架；
- 是“复盘型”——强调结果、问题、动作；
- 是“规划型”——强调下阶段路径与关键动作。

主命题必须能压成一句结果型标题，例如：

- `一场直播体系升级，带来更稳的增长曲线`
- `从粗放开播到梯队化运营，一张图看懂关键变化`
- `守住效率、放大增量、为旺季蓄力`

#### 第 2 步：把全文折叠成 3~5 个信息块

默认采用以下模块结构，按内容适配，不必机械照搬：

1. **头部结论 / 战绩**
2. **关键指标卡片**
3. **核心原因 / 能力建设**
4. **梯队或结构变化**
5. **下阶段策略 / 路线图**

约束：

- 每个模块只保留最有识别度的 1 句主结论。
- 关键词优先于整段句子。
- 模块数尽量不超过 5。
- 手机端竖版时，优先保证“从上到下 5 秒读懂”，而不是覆盖所有细节。

#### 第 3 步：重写成“图面语言”

把文档语言改写成适合图面的短句：

- 文档原句：`主播梯队搭建初具规模，逐步形成金字塔结构`
- 图面语言：`主播梯队成型：头部领跑，中腰部补位，新人持续上岗`

重写规则：

- 一句尽量不超过 20 个汉字；
- 优先用动词和结果词；
- 避免长定语、书面腔、汇报腔；
- 允许用 `→`、`+`、`↑`、`稳住`、`放大` 等轻量视觉符号。

### 4. 脱敏模式（命中即执行）

当用户提到“脱敏”“不要人名数字”“敏感内容处理”等要求时，必须开启脱敏模式。

默认脱敏规则：

- **人名**：改为角色称谓，例如“核心主播 / 中坚主播 / 新主播群”。
- **品牌名 / 店铺名**：若有敏感性，改为“某品牌 / 某店铺 / 项目组”。
- **精确金额**：改成量级、区间或趋势表达，例如“6.8 万”→“数万级”。
- **精确份额 / 排名**：改成“头部 / 领先 / 第一梯队 / Top 阵营”。
- **可保留项**：若用户允许，可保留百分比变化和方向性指标；若未明确，优先保留趋势，不保留过细绝对值。

需要进一步收紧时，参考 [脱敏规则](references/desensitization-rules.md)。

### 5. 关键指标卡片策略

指标卡片不是简单抄原文，而是要围绕“这张图想让人记住什么”来选。

默认优先级：

1. **结果指标**：GMV、订单、转化、粉丝增长
2. **效率指标**：时均产出、直播时长、零产出率、CTR
3. **结构指标**：主播梯队、店播占比、店铺带动
4. **阶段目标**：Q4、旺季、下阶段重点

当用户明确指定要替换某几张卡片时，以用户要求为准，不得保留旧口径偷懒复用。

### 6. 视觉表达规则

- 风格：手绘、暖色或轻松配色、少量涂鸦感元素。
- 元素：图标、箭头、气泡框、金字塔、路线图、卡片分区。
- 留白：宁可少写，不要挤满。
- 阅读路径：从标题 → KPI → 方法/结构 → 下一步。
- 趣味度：只做辅助，不抢结论。
- 专业感：避免儿童绘本化；应保持“运营复盘海报”的成熟感。

版式选型参考：[布局模式](references/layout-patterns.md)

### 7. 输出形式

根据任务需要，输出其中一种或组合：

#### A. 信息图结构稿

```text
【标题】
【副标题/一句话方法论】
【模块1】
【模块2】
【模块3】
【模块4（可选）】
【模块5（可选）】
【视觉元素建议】
【配色与版式建议】
```

#### B. 图像生成提示词

必须包含：

- 画布比例
- 语言（中文）
- 风格（手绘卡通）
- 内容块布局
- 关键词
- 脱敏要求（若适用）
- 禁止信息拥挤

#### C. 修改说明

若是在已有图稿上迭代，必须显式列出：

- 删掉了什么
- 替换了什么
- 进一步模糊了什么
- 保留了什么风格不变

### 9. 合规默认值（Defaults / L2）

- 默认语言：中文简体
- 默认版式：9:16 竖版
- 默认阅读终端：手机端
- 默认模块数：4
- 默认风格：手绘卡通 + 专业复盘感
- 默认数字策略：若未要求脱敏，可保留关键增长率；若用户提到敏感，则优先模糊绝对数
- 默认卡片数：3
- 默认信息密度：每个模块 1 个主结论 + 少量关键词

### 10. 运行前校验（L3 Runtime Gate）

在进入图像生成前，若已经把信息结构整理成 JSON 规格，先运行本地校验脚本，确认结构没有带病进入生成阶段：

```bash
python3 scripts/validate_infographic_spec.py --file infographic_spec.json
```

推荐 JSON 结构：

```json
{
  "title": "一张图看懂直播体系升级后的增长成果",
  "ratio": "9:16",
  "language": "中文简体",
  "style": "手绘卡通",
  "modules": [
    {"heading": "关键战绩", "bullets": ["增长更稳", "效率提升"]},
    {"heading": "关键指标卡片", "bullets": ["直播时长", "新增粉丝", "带动店铺 GMV 增长"]},
    {"heading": "下阶段动作", "bullets": ["守效率", "练梯队", "备旺季"]}
  ]
}
```

如果以下任一情况出现，脚本会 `raise` 并阻止继续：

- 缺失标题、比例、语言、风格或模块；
- 模块数少于 3 或多于 5；
- 单模块 bullets 过多；
- 比例不是 `9:16` / `16:9`；
- 语言不是中文。

### 11. 约束条件

- 不得在未读取源材料前直接脑补内容。
- 不得把整段文案原样塞进图片。
- 不得为了“卡通感”牺牲信息可读性。
- 不得忽略用户指定的替换卡片口径。
- 命中脱敏模式后，不得残留真实敏感实体。
- 不得输出超过手机端承载能力的大段文本。
- 如果原材料信息过多，必须主动裁剪，而不是全部堆上图。
