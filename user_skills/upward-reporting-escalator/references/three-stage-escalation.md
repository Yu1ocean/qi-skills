# 三阶升级法：从执行稿到决策稿

## 1. 三轮优化里真正发生了什么

### 第一轮 → 第二轮

不是“把原文缩短”，而是把文本回答的问题从：
- **我们做了什么**

改成：
- **现在怎么看，最关键的卡点是什么**

这一轮的语言动作通常包括：
1. 删除并列动作堆叠。
2. 抽出 1-2 条核心判断。
3. 把动作改写为支撑判断的 2-3 层抓手。

### 第二轮 → 第三轮

不是“再加更多细节”，而是把判断升级成可供讨论的方案：
- 判断为什么成立
- 谁负责哪一段
- 目标、时间窗、业务贡献是什么
- 需要上级支持什么，或下一步要验证什么

这一轮的语言动作通常包括：
1. 补责任链和协同边界。
2. 给数字加上目标锚点和时间窗。
3. 把下一步动作写成资源配置问题，而不是执行清单。

## 2. 每一阶分别回答什么问题

| 台阶 | 回答的问题 | 典型开头 | 常见失败方式 |
| --- | --- | --- | --- |
| 执行稿 | 我们做了什么 | 这周我们推进了… | 领导需要自己拼图 |
| 判断稿 | 现在怎么看 | 当前判断是… / 对比上月我们有两点新判断… | 有结论，但没绑定责任链 |
| 决策稿 | 基于判断怎么推进 | 基于这个判断，下一阶段把动作收束为… | 写长了，但仍无法支持拍板 |

## 3. 决策稿的五个硬锚点

1. **判断锚**：现在最关键的变化/问题是什么。
2. **责任锚**：谁负责哪一段，谁需要协同。
3. **目标锚**：这件事最终支撑什么业务目标。
4. **时间锚**：在哪个时间窗完成，为什么是现在。
5. **验证锚**：下一步要验证什么，或需要什么支持。

## 4. 可直接复用的升级模板

### 模板 A｜执行稿 → 判断稿

```text
当前判断是，________。相较于此前，当前最关键的变化在于________。因此，下一阶段动作不再平铺推进，而是收束为________、________两到三条主线。
```

### 模板 B｜判断稿 → 决策稿

```text
基于上述判断，下一阶段把动作收束为三层：第一，________，由________负责，目标是________；第二，________，在________时间窗内完成，支撑________；第三，________，用于验证/解决________。若上述链路不足以支撑目标，则需要________支持。
```

## 5. 适用边界

适合：
- 管理层汇报
- 项目阶段复盘
- 资源申请
- 周报/月报升级

不必强套：
- 纯通知型消息
- 单点执行同步
- 没有业务判断空间的机械播报

## 6. L5 Seller-focused Roles 对标层

当汇报材料涉及绩效自评、职级校准、招商/商家增长、区域/类目 owner 或用户明确要求对齐 L5 时，三阶升级之后必须追加 L5 对标。这个模块比较的不是文风，而是“L5 要求的判断力 vs 当前稿件实际呈现的判断力”。

### 6.1 L5 的核心判断力

L5 Seller-focused Roles 的核心定位是领域专家：能针对新兴/小市场类目，或成熟大市场中的细分类目，制定全局发展策略，并通过创新商家模式实现业务规模化。它不是“更熟练的执行者”，而是能定义问题、设计机制、撬动生态、验证结果的 owner。

    </tr>
    <tr>

    </tr>
    <tr>
        <td>结构性解法</td>
        <td>沉淀标准、分层、机制、流程和 Playbook，解决体系性问题。</td>
        <td>动作很多，但没有变成可复用资产。</td>
    </tr>
    <tr>
        <td>生态协同</td>
        <td>联动品牌、服务商、产品、市场、招商、运营、区域等伙伴。</td>
        <td>只写个人推动，没有说明协同方、责任边界和共同结果。</td>
    </tr>
    <tr>
        <td>外部影响力</td>
        <td>能在品牌高层、行业组织、政府对口方或关键商家处建立影响力。</td>
        <td>如果有关键外部谈判却没写，会低估 owner 影响力。</td>
    </tr>
    <tr>
        <td>卖家策略</td>
        <td>基于 cohort / 分层 / 分群制定卖家策略并验证结果。</td>
        <td>只写商家名单，不写分层逻辑、资源配置和验证闭环。</td>
    </tr>
</table>

### 6.3 输出模板

```text
L5 gap 分析：
当前判断力层级：执行型 / 判断型 / L5 owner 型。
已体现的 L5 维度：……（绑定原文证据）
主要 gap：……（按角色定位 / 策略判断 / 结构性解法 / 生态协同 / 卖家策略等维度说明）
具体改写建议：……（给出可直接替换的句子或段落）
证据待补：……（列出还需要补的数字、案例、协同方、资源诉求或验证点）
```
