# 来源可信度与降噪口径（Source Scoring）

本文件用于在“信息噪声大、观点冲突强、需要做结论背书等级划分”的场景下，统一来源分层与可信度描述口径。

## 1. 来源分层（优先级从高到低）

### S 级：一手事实（最高优先级）
- 官方公告/新闻稿原文（公司官网、监管官网、交易所公告等）
- 法律法规/政策原文
- 学术论文/标准/专利原文
- 财报、招股书、官方统计公报

**使用方式**：
- 用于 L1（事实层）的核心证据。
- 引用时给出：发布时间/版本号/发布主体。

### A 级：权威二手解读
- 头部媒体的深度报道（有明确采访对象、可核查数据）
- 行业研究机构公开报告（声明数据来源与方法）
- 大型开源社区/基金会的技术报告

**使用方式**：
- 用于 L2（解释层）的主要依据。
- 对关键数字仍应尝试回溯至 S 级。

### B 级：可验证的社区/从业者信息
- 开发者论坛、技术博客（作者身份可验证，给出复现步骤/数据）
- 一线从业者公开演讲稿/Slides/访谈（可追溯）

**使用方式**：
- 用于补充背景、案例、机制推断。
- 对结论只提供“线索级支撑”，除非能回溯到 S/A。

### C 级：噪声源（谨慎引用）
- 转载聚合站、标题党内容
- 无法核验作者/来源/时间的信息
- 明显带货/强营销/强立场的内容

**使用方式**：
- 一般不用于支撑关键结论。
- 可用于“舆论/叙事分布”的素材，但必须标注其低可信度。

## 2. 交叉验证规则（强约束）

- **关键结论（出现在 TL;DR 或 L4 行动建议中的结论）**：
  - 至少 2 个独立来源支持，其中至少 1 个为 S 或 A。
- **单一来源结论**：
  - 必须标注“待验证”，并列出需要补证的材料类型（例如“监管原文/财报/官方公告/论文”）。
- **转载链处理**：
  - 转载不算新增来源；尽量定位原始发布点。

## 3. 常见噪声与对策

- **时间噪声**：旧闻被重新传播
  - 对策：优先记录“原始发布时间”，并在摘要中声明检索截止。

- **口径漂移**：同一指标不同机构定义不同
  - 对策：在引用数字时补充“口径定义/统计范围/样本”。

- **叙事偏差**：观点型文章用情绪替代证据
  - 对策：将观点拆解为可证伪命题，再去找证据。

- **幸存者偏差**：只看成功案例
  - 对策：主动寻找失败案例/反例/否定证据。

## 4. 报告中的推荐措辞（可直接复用）

- “根据【S 级一手材料】……（URL）可确认……”
- “多家来源一致指出……但仍缺少……（待验证）”
- “该观点主要来自……（B/C 级），目前缺少一手证据支撑，因此仅作为线索保留。”
