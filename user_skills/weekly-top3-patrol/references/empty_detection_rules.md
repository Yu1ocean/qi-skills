# 「未填写」识别规则

本文档定义 weekly-top3-patrol 在扫描 Wiki Bitable 时如何判定一条记录为"未填写"。

## 三选一判定标准

满足以下任一条件即视为"未填写"：

1. **关键字段为空**：
   - "本周三件事 / Top3" 字段为 `null` / `""` / 仅含空白字符
   - "负责人" 或 "Owner" 字段非空但当周对应的目标列为空

2. **占位符为默认值**：
   - 字段值匹配 `["TBD", "待填", "n/a", "N/A", "—", "/", "待定"]` 之一（大小写不敏感）

3. **当周未提交**：
   - "更新时间 / 提交时间" 字段早于本周一 00:00（CST）
   - 即上周或更早填写后未在本周更新

## 识别字段优先级

```python
FIELD_CANDIDATES = [
    "本周三件事",
    "Top3",
    "Weekly Top3",
    "本周重要三件事",
]
```

按优先级取第一个匹配的字段；若全部缺失，整条记录视为"配置异常"，进入 DLQ 而非 pending 名单。

## 边界情况

- **多语言混合**：识别以中文/英文双轨进行，匹配正则 `(?i)(top\s*3|三件事)`
- **历史归档**：状态字段含 "已归档 / Archived" 的记录直接跳过，不进入巡检
- **新员工**：入职时间 < 本周一的记录给予 "豁免一周" 软宽限，仅在 Mode A 提示，不进入 Mode B 强插
