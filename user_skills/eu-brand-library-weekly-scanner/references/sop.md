# 欧洲跨境品牌库·周扫归档技能 SOP（v1.4）

## 📌 技能简介

`eu-brand-library-weekly-scanner` 用于每周自动维护「欧洲跨境品牌库」：先自动发现候选数据源（方案B：人工确认扩源），再扫描「已收录数据源清单」中所有状态为「活跃」的源，将正文中明确出现的新品牌信息补录到「跨境品牌库」飞书表格，并执行写后 RAW 回捞校验。它解决的是“内容源线索 → 品牌库结构化资产”的重复维护问题，适合欧洲跨境品牌招商、市场研究和品牌库周更场景。

## 🔑 触发词

- 核心关键词：欧洲品牌库周扫、跨境品牌库补录、eu-brand-library-weekly-scanner
- 典型指令示例：
  > 请扫描本周所有已收录（活跃）数据源，把新增品牌补录到跨境品牌库；另外给我 5 个待确认的新候选源。

## ⚙️ 核心架构 / SOP / 约束条件

### 编排执行模式（v1.4 新增）

- 若主进程已派发子特工执行完整周扫，父任务必须立刻进入 `wait_async_task`，只做等待与最终收口。
- 父任务在等待期间不得重复执行搜索、网页抓取、品牌提取、飞书写入、候选源整理或消息发送。
- 一个运行窗口只能保留一个业务执行器：父任务自跑或子特工跑，二选一。
- 子特工已完成写表与 RAW 回捞时，父任务禁止二次写表。

### 0. 数据源自动发现（方案B：人工确认扩源）

- **候选搜索**：使用搜索能力（info-miner/网络搜索）以「欧洲跨境」「欧洲出海」「跨境品牌」「EU ecommerce 出海」等关键词，每次发现 Top 5 候选源。
- **质量评分**：按 `memory/topics/eu-brand-scanner-datasource-judgment.md` 的准入标准自动打分：通过 / 待确认 / 排除。
- **去重**：读取同一份判断文档中的「已收录数据源清单（SSOT）」，避免重复推荐已在库的源。
- **候选卡片输出**：仅将「待确认」级别候选源整理为结构化列表（名称、类型、理由、链接），通过 result 返回给主进程，由主进程发给用户确认。
- **入库门禁**：用户确认后，才允许把新源追加写入 `memory/topics/eu-brand-scanner-datasource-judgment.md` 的「已收录数据源清单」与「历史候选记录」。未确认不得擅自扩源。

### 1. 输入与默认资产

- 数据源判断 SSOT：`memory/topics/eu-brand-scanner-datasource-judgment.md`
- 目标品牌库：`https://bytedance.my.larkoffice.com/sheets/S91BsutWshyGK9tcAapmoeYkyQb`
- 类目标准表：`https://bytedance.larkoffice.com/sheets/shtcnYzaobnxlPVGox8hmSZ8b8d`（字段：`lvl1_cate_name`）

### 2. 扫描公众号合集（多源）

扫描范围为 `memory/topics/eu-brand-scanner-datasource-judgment.md` 的「已收录数据源清单（SSOT）」中所有状态为「活跃」的数据源。对每个活跃源，进入其合集/文章列表页，默认扫描本周新增文章；如果用户指定数量，则扫描最新 N 篇。每篇文章必须保留真实 `mp.weixin.qq.com` 原文链接、标题和发布时间。无法获取真实原文链接时，该文章不得进入品牌提取环节。

### 3. 品牌信息提取

对每篇新文章调用 `user_skills/info-miner` 做正文读取和信息提取。字段包括品牌名中文、品牌名英文、所属一级类目、目标市场/销售渠道、简介摘要、来源链接、文章标题和发布时间。正文未提及字段必须留空，禁止根据外部常识补全。

### 4. 类目对齐

读取 Global Tree 20260427 标准表中的 `lvl1_cate_name`，将文章类目映射为标准一级类目。无法唯一映射时留空，并在摘要中记录“类目无法零信任对齐”。

### 5. 去重与增量判定

读取目标表格表头与既有品牌名，按表头语义定位中文品牌名和英文品牌名列。中文或英文任一命中即跳过。去重后仅保留真正新增品牌。

### 6. 写入和 RAW 回捞

调用 `user_skills/feishu-doc-writing-guide` 包装器写入，按表头列位倒序插入第 2 行。禁止裸调原生 lark 写入工具，禁止全表覆盖，禁止删除旧数据。写入后立即 RAW 回捞，核对新增行数量、品牌名、来源链接和关键字段。

### 7. 输出运行摘要

摘要必须包含扫描源数量、扫描篇数、新增品牌数、写入行数、失败/跳过原因。若新增为 0，也要说明扫描范围和去重依据。
