# 输出契约 (Output Contract) — 字段级解释 + 反例库

本技能任何一次"演讲知识沉淀"任务的最终飞书文档，必须严格满足：

> **100 字高光 + 全局大纲 + 多主题 L1-L4 + 秒级时间戳 + 空降链接 + 高精逐字稿附录**

## 字段级解释

| 字段 | 物理体现 | 强制要求 | 反例（不合规） |
|---|---|---|---|
| 100 字高光 | `## 📌 核心高光（100 字）` | 去空格后 ≤ 220 字符；必须围绕中心主张 | 写成"会议总结"流水账；超过 300 字 |
| 全局大纲 | `## 📚 全局大纲` | 5 ~ 10 条 L1 方向条目，倒树形 | 只有 1 条 / 没有 L1，混入论据 |
| 多主题 L1-L4 切片 | `## 🧭 多主题深度切片（L1-L4 + 秒级时间戳）` | 至少 3 个 L1；每个 L4 都附时间戳 | L4 没有时间戳；缺 L3 直接 L2→L4 |
| 秒级时间戳 | `[HH:MM:SS]` 或 `[<file> @ HH:MM:SS]` | 不得只精确到分钟；本地音频走 `[<file> @ ...]` 形式 | `[10 多分钟那段]`、`[大约 5 分钟]` |
| 空降链接 | URL：`?t=<秒>`；本地：`[<file> @ HH:MM:SS]` | 视频源必须真实可点击；本地音频明确说明非链接 | 把本地音频写成 `https://example.com?t=120` |
| 高精逐字稿附录 | `## 📖 高精逐字稿（附录，全量｜源文件：…）` | 不分页拆段，全量保留时间戳 | 用"以下省略 200 行"；对附录二次摘要 |

## 反例库（来自历史复盘）

1. **隐性丢段**：ASR 失败后既没重试也没标 GAP，附录看似流畅但实际跳过了 12-15 分钟。✗
2. **时间戳塌陷**：单段内部时间戳没加 segment offset，多个片段全部从 `[00:00:00]` 开始，跳转点全部错位。✗
3. **大纲幻觉**：L4 案例在逐字稿里搜不到原文；zero-trust-qa-checker 抽样直接 FAILED。✗
4. **附录二次精简**：把 4 万字逐字稿压缩成"摘要附录"，违反"全量、不分页拆段"约束。✗

## 与 zero-trust-qa-checker 的衔接

- Phase 1 契约：见 `qa-manifest-template.json`，对 `build_outline.py` 产出的骨架做主键 / 非空 / 类型校验。
- Phase 4 物理回捞：建议补充 `physical_probe.match_rules`，把 outline 中抽样金句的 regex 喂给 v3 引擎，去 `transcript_full.md` 中物理搜索。
