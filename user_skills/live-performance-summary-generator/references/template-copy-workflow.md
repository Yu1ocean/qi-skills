# 模版副本工作流（V1.4）

## 模版源

- 模版文件：`https://dyqe3ary97.larksuite.com/sheets/VVeQshKyvhyK7stx4gbuqOQ4sBb`
- 模版 raw sheet：`1. 数据底表`
- 模版 summary sheet：`2. 计算汇总`

## 为什么必须先复制整表

这份技能从 V1.4 起默认采用“副本化分析”而不是“原表反复复用”：

1. 模版文件只承担结构母版职责，不承担某次分析的数据承载职责。
2. raw sheet 与 summary sheet 的格式、冻结、列宽、辅助说明都依赖整份文件的现成结构，复制整表最稳。
3. 这样每次分析都有独立留档，便于回看、对比和追责，也避免误覆盖历史分析结果。

## 标准 SOP

1. 先复制整份模版文件
2. 在副本 `1. 数据底表` 贴入本次 raw 数据
3. 在副本上运行 `scripts/generate_summary_sheet.py`
4. 检查副本 `2. 计算汇总` 是否生成完成
5. 如需分享、归档、复盘，都基于副本进行

## 红线

- 禁止直接在模版本体粘贴 raw 数据
- 禁止直接在模版本体执行 summary 重建
- 禁止把某次分析完成后的副本再当成下一次分析的新模版

## 最小验收

- 本次分析使用的是模版副本，而不是模版本体
- 副本中 `1. 数据底表` 与 `2. 计算汇总` 均存在
- summary 的冻结、表头、公式区、benchmark 标红符合模版约定
