# 全域资产归档员 (omni-asset-archiver) v4.1

负责执行资产归档任务，确保数据精准、安全地记录到指定台账中。

## 适用场景
- **风神链接即刻归档**：识别到 Aeolus（风神）看板链接时触发。
- **项目复盘沉淀**：将除虫复盘、故障修复报告、架构演进文档索引至图书馆。
- **专属技能清单同步**：当新技能创建或现有技能迭代时，同步更新技能台账。
- **日报/台账备份**：同步 Daily Log。

## 执行规范

### 1. 目标坐标
使用以下硬编码地址，无需重复确认：
- **主台账 Token**: `ECQ0sDwmbhDex9tcUSjlkU7Bgdh`
- **常用风神链接 Sheet**: `常用风神链接`
- **图书馆 Sheet**: `图书馆` 或 `NGQoJo`
- **专属技能清单 Sheet**: `专属技能清单_Sheet`
- **灵感画廊 Bitable**: `PRbvbUyLqaeITqsXNMRcRCM5nhh` (Table: `tblHHVXl9ObjSyRw`)

### 2. 触发机制
- **事件驱动**：在对话中收到任何风神（Aeolus）看板链接或技能元数据更新时，应立刻执行归档逻辑。

### 3. 行列约束与校验 (Schema Guard)
写入操作需严格符合以下物理契约映射规则：

#### 场景 A：风神链接归档
- **写入规则**: 单行追加。
- **列映射**:
  - **A 列**: 看板名称
  - **B 列**: 风神直达链接 URL
  - **C 列**: 收录日期 (YYYY-MM-DD)
  - **D 列**: 业务上下文/备注
- **强制校验**: 写入前确认上述 4 个字段完整，防止残缺数据入库。

#### 场景 B：日常台账归档
- **写入规则**: 单行追加。
- **列映射**:
  - **A 列**: 编号/日期
  - **B 列**: 名称/超链接
  - **C 列**: 描述/备注

#### 场景 C：专属技能清单归档 (Schema Guard V4 强校验)
- **写入规则**: 匹配技能编号更新或单行追加。
- **列映射**:
  - **A 列**: 技能编号 (Skill ID)
  - **B 列**: 技能名称 + 说明文档链接 (使用 HYPERLINK 公式合并)
  - **C 列**: 功能描述 (Function Description)
  - **D 列**: 版本号 (Version)
  - **E 列**: 更新时间 (YYYY-MM-DD HH:MM)
- **物理契约校验**: 
  - 必须确保 A-E 五列数据全量存在且格式正确。
  - 技能编号必须唯一。
  - B列必须使用 `=HYPERLINK("URL", "Name")` 格式。

### 4. 报告类资产的【文档生动化标准】
- **适用范围**：当归档对象属于“复盘报告”“故障修复报告”或“架构演进报告”时，本标准强制生效。
- **前置动作**：归档前必须检查目标飞书文档头部概览区是否已前置内嵌“灵感故事”与“视觉卡片链接”；若缺失，必须先联动 `cyber-inspiration-generator` 生成。
- **最小验收项**：文档概览区至少可见以下 4 项：`灵感标题`、`阿加莎/赛博朋克风格小说段落`、`冷静事实说明`、`卡片链接`。
- **归档熔断规则**：若上述 4 项任一缺失，或卡片尚未生成成功，禁止将该文档写入【图书馆】或任何报告类台账，必须向用户明确说明“文档生动化标准未完成”。
- **写入备注要求**：归档时在备注/描述字段中标记该文档已完成“灵感卡片前置嵌入”，便于后续巡检和二次回捞。

### 5. 数据预处理与安全写入
- **格式化**: 日期统一为 `YYYY-MM-DD`，更新时间含分钟。
- **超链接**: 链接字段使用 `=HYPERLINK("URL", "名称")` 公式。
- **强制 RAW 写入**: **必须且仅能**调用 `user_skills/feishu-doc-writing-guide/scripts/safe_insert_sheet_row.py` 执行写入。
- **高权限通道**: 调用脚本时必须包含 `include_secrets=true` 以加载 `AIME_USER_CLOUD_JWT` 凭证。
- **校验反馈**: 脚本执行失败（RAW 锁校验不通过）时，必须立即向用户报告物理写入异常，严禁“假装成功”。
