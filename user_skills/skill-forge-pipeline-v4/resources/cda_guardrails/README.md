# resources/cda_guardrails

这里存放 CDA Guardrails（认知-默认-断言 三层防御）在 Forge 阶段自检失败时的“对照修复材料”。

- `anti_examples.md`：3 个高频反例 + 正例修正片段
- `pseudocode_template.py`：可复制的 validate_inputs / GuardrailViolation 模板
- `skill_assessment_example.md`：一次性评估快照（用于对齐风险分级和缺口类型）

配套自检脚本：`scripts/cda_guardrails_selfcheck.py`
