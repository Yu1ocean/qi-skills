# 视频脚本拆解检查清单

在需要更细颗粒度审阅时，按以下顺序检查：

## 1. 入口层
- 标题/封面/开场文案承诺了什么？
- 用户为什么会停下来？是反差、利益、冲突、悬念、身份认同，还是视觉异常？
- 前 3 秒是否明确给出“继续看下去的理由”？

## 2. 结构层
- 开场钩子：用什么方式抓住注意力？
- 主体推进：内容按什么逻辑展开？（问题→冲突→转折→解法 / 观点→证据→案例 / 痛点→方案→结果）
- 节奏变化：哪里加速、哪里放慢、哪里做停顿？
- 收口动作：最后是升华、反转、行动号召，还是留下悬念？

## 3. 情绪层
- 情绪起点是什么？
- 中段是否有拉升点（紧张、期待、爽感、共鸣、好奇）？
- 高潮点出现在哪里？
- 尾段是释放、转化还是余味？

## 4. 信息层
- 信息密度高点在哪？
- 是否存在“废话段”或重复段？
- 哪些句子是真正的金句、观点句、转发句？
- 是否给了具体数字、案例、画面或强证据？

## 5. 转化层
- 视频希望用户做什么？
- CTA 是显性还是隐性？
- CTA 出现的时机是否过早/过晚？
- 是否有增强转化的信任要素（真实案例、对比、结果展示、身份背书）？

## 6. 输出时必须落到这 6 项
1. 视频画像
2. 时间轴拆解
3. 高效原因
4. 风险与短板
5. 可复用方法论
6. 下一版 AB 实验建议
