# 常见视频脚本模板

## 1. 口播知识型

### 模板
- 钩子：先扔一个反常识判断 / 高价值承诺
- 铺垫：说明这件事为什么重要
- 主体：给 3 个关键点
- 收口：一句结论 + CTA

### 例子骨架
1. 你以为 `<常见认知>` 才重要，其实真正决定 `<结果>` 的是 `<反常识点>`。
2. 如果你只记住一件事，就是 `<核心结论>`。
3. 下面我只讲 3 点：`<点1>`、`<点2>`、`<点3>`。
4. 最后，如果你也在做 `<场景>`，先从 `<动作>` 开始。

## 2. 剧情反转型
- 开场：直接抛冲突
- 中段：制造误导或预期
- 后段：反转揭晓
- 收口：价值升华 / 金句

## 3. 测评对比型
- 开场：给明确对比对象与决策问题
- 中段：按 3~5 个维度快速对比
- 高潮：给出最关键差异
- 收口：给适用人群结论

## 4. 带货种草型
- 开场：痛点 + 结果预告
- 中段：展示使用前后 / 核心卖点 / 真实细节
- 高潮：打消顾虑（价格、质量、适配性）
- 收口：明确 CTA（购买、咨询、领取）

## 5. 好钩子公式
- 反差式："最没用的动作，反而救了我。"
- 利益式："这 30 秒，帮你少走 3 个月弯路。"
- 悬念式："真正让人停下来看的，不是内容本身。"
- 身份式："如果你也是新手，这条一定要看完。"
- 冲突式："大家都在拼命讲卖点，但真正起量的不是卖点。"

## 6. AB 实验建议模板
- A 版只改钩子，不改主体
- B 版只改 CTA 位置，不改前文
- 每次只动一个变量，避免归因污染
- 记录：3 秒留存、完整播放率、互动率、点击率/转化率
