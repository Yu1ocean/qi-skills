## 📌 技能简介

`video-script` 用来把“好视频为什么有效”拆成可复用的方法论资产。它不只做观后感，而是把视频还原成 **钩子、结构、情绪、信息密度、CTA** 五条主线，并输出可以直接复用的脚本模板与 AB 实验建议。

## 🔑 触发词

- 核心关键词：

  - 视频脚本
  - 爆款视频拆解
  - 黄金前三秒
  - 情绪曲线
  - 短视频方法论
- 典型指令示例：

  > 拆一下这条视频为什么有效，沉淀成脚本方法论把这段逐字稿拆成可复用的短视频脚本结构

## ⚙️ 核心架构 / SOP / 约束条件

1. **先判定输入类型**：区分视频链接、逐字稿、脚本文案，还是只有主题。
2. **建立视频画像**：明确受众、承诺、目标动作与视频类型。
3. **拆黄金前三秒**：识别反差、利益、悬念、身份、冲突五类钩子。
4. **拆主体推进**：将内容还原为问题→解法、冲突→反转、观点→证据等结构骨架。
5. **看情绪曲线与信息密度**：找出拉升点、高潮点、拖沓段。
6. **拆 CTA 与转化**：判断是否有清晰的行动引导与信任背书。
7. **抽象方法论**：沉淀为钩子公式、结构骨架、金句写法、CTA 原则。
8. **给模板与实验建议**：输出可复用脚本模板，并用单变量 AB 实验验证。

<callout emoji="💡">
**默认输出六段：** 视频画像、结构拆解、高效原因、风险短板、可复用方法论、AB 实验建议。
</callout>

## 📖 案例实录 (Best Practice)

- **用户输入：**

  ```Plain Text
  帮我拆一下这个爆款短视频的方法论，重点看前三秒和情绪曲线。
  
  ```
- **标准输出：**

  1. 视频画像：这条内容在跟谁说、承诺了什么。
  2. 前 3 秒钩子：属于哪类抓注意力机制。
  3. 主体结构：每一段承担什么任务。
  4. 情绪曲线：起点、拉升点、高潮、收口。
  5. 可复用方法论：以后同类视频可以直接套什么框架。
  6. AB 实验：下一版先只改钩子或 CTA，观察对应指标。
