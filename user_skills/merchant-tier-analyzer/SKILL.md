# 商家层级分析器 (merchant-tier-analyzer) V2.0

本技能专用于深度拆解商家层级结构（T1-T5），分析头部与长尾商家的价值分布，并生成符合 v6 规范的“长尾放大”全景报表。

**Global ID**: SKL-2604-001
**Version**: V2.0

## 核心功能
1.  **三位一体报表输出**：自动生成包含以下 3 个 Sheet 的飞书电子表格：
    - `Raw data`: 结构化清洗后的商家原始明细。
    - `商家结构矩阵`: 跨国家、类目的 T1-T5 商家数量与 GMV 占比矩阵。
    - `近6个月增长表`: 核心指标的时间序列趋势分析。
2.  **v6 全景制图能力**：集成 `v6-panoramic-chart-generator` 逻辑，处理长尾商家分布。
    - **长尾断轴**：解决 T1 商家数极多导致 T5 无法看清的问题。
    - **非线性占比分割**：放大 T5 等高价值但低占比人群的视觉存在感。

## 业务逻辑约束（V2.0 升级）
- **层级定义**：
  - **T5**: 顶尖头部（Tier 5），贡献绝大部分 GMV 但商家数极少（通常 <0.5%）。
  - **T1**: 极长尾（Tier 1），商家数占比极高（通常 >90%）但单店贡献低。
- **数据结构线**：
  - 必须对齐 `Region`, `Category`, `Merchant_ID`, `GMV`, `Tier` 等核心维度。

## 执行工作流
1.  **前置解析**：分析输入文件（xlsx/csv）的商家分层口径（通常读取 `gmv_tier`）。
2.  **矩阵构建**：执行透视聚合，计算各层级的 Count % 和 GMV %。
3.  **趋势挖掘**：提取最近 6 个月的数据，计算复合增长率或 MoM。
4.  **图表生成**：调用内置模块绘制 v6 断轴对比图。
5.  **交付与归档**：调用 `mcp_lark_create_lark_table` 生成表格，并通过 `omni-asset-archiver` 归档。
